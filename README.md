# 🏋️‍♂️ Fitnest Azerbaijan - Android Application

Fitnest Azerbaijan is a modern Android mobile application built using **Jetpack Compose**. It features a clean UI/UX designed for gym discovery, Market discounts, user profile management, and interactive navigation, fully adhering to Material 3 guidelines.

---

## ✨ Features

* **🎨 Modern UI/UX:** Built with 100% Declarative UI using Jetpack Compose following the Figma design closely.
* **🌙 Dark & Light Theme:** Complete dynamic color system support (`MaterialTheme.colorScheme`) that adapts seamlessly to system preferences.
* **🗺️ Seamless Navigation:** Bottom Navigation integration utilizing `Jetpack Navigation Compose` with backstack management.
* **🏋️ Gym & Market Discovery:** Dynamic listing of nearby fitness centers and specialized market discount products.
* **👤 User Profile Management:** Interactive profile interface with user detail controls and subscription status cards.
* **🖼️ Asynchronous Image Loading:** High-performance remote image fetching and caching powered by **Coil**.

## 🛠️ Tech Stack & Libraries

* **Language:** [Kotlin](https://kotlinlang.org/)
* **UI Framework:** [Jetpack Compose](https://developer.android.android.com/jetpack/compose)
* **Design System:** [Material 3](https://m3.material.io/)
* **Navigation:** [Navigation Compose](https://developer.android.android.com/jetpack/compose/navigation)
* **Image Loading:** [Coil Compose](https://coil-kt.github.io/coil/compose/)
* **Architecture:** Single Activity Architecture with Composable screen graphs.
